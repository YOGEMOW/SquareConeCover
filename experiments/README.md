# 实验登记

本目录存放所有可复现实验。规则：

1. 每个实验一个文件，命名 `E####-short-title.md`，编号递增、不复用、不跳号；
2. 使用 `TEMPLATE.md` 的结构；
3. 结论必须回写到 `docs/`，并在 PR 中引用实验编号；
4. 脚本放 `experiments/scripts/`（或把最小可运行代码贴在实验文件内）；
5. 失败的实验同样保留并标注"未通过"，不许删除。

状态标记：`待认领` / `进行中` / `已通过` / `未通过` / `已废弃`。
