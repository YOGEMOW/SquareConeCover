## 假设

docs/02 给出的 Θ、δ、侧面积公式及其极限行为正确，可作为后续算法与验收的数学基础。

## 待验证命题

1. 圆底（A = B）时 Θ = 2πA/√(H²+A²)；
2. 一般椭底时 Θ = ∫₀^{2π} |p′×(p−apex)| / |p−apex|² dt，其中 p(t) = (A cos t, 0, B sin t)、apex = (0, H, 0)；
3. 极限：H→0 时 Θ→2π；H→∞ 时 Θ→0；
4. 极限：B→0 且 H 固定时 Θ→4·atan(A/H)；
5. 侧面积公式在圆底时等于 π·A·√(H²+A²)；
6. 独立校验：把锥面展开（φ(t) = ∫ dφ/dt），比较展开底口折线长度与三维底口曲线长度，相对误差应随采样加密而下降。

## 判据

- 命题 1、5（解析对照）：相对误差 < 1e-10；
- 命题 3、4（极限）：参数趋近极限时误差 < 1e-6；
- 命题 6（独立展开）：N = 10⁵ 时相对误差 < 1e-3，且随 N 增大单调下降。

## 实现提示

- 用高阶一维积分（Gauss-Legendre 或复合 Simpson，N ≥ 10⁵）；
- B = 0 或 H = 0 是奇异点：用极限解析式，不要直接数值积分；
- 输出 CSV：配置名, A, B, H, Θ_deg, δ_deg, 侧面积, 方法, 相对误差。
