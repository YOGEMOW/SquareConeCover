## 假设

docs/02 给出的 Θ、δ、侧面积公式及其极限行为正确，可作为后续算法与验收指标的数学基础。

## 方法

- 脚本：`experiments/scripts/E0001_cone_formula_check.py`（纯 Python 标准库，无第三方依赖）；
- 数值方法：周期梯形法（光滑周期函数上指数收敛），N = 2^18（默认）、2^19（小 B 极限）；
- 解析对照：圆底 Θ = 2πA/√(H²+A²)、侧面积 = πA√(H²+A²)；
- 展开等距验证：以数值微分检查度量一致性 |p′|² = L′² + (L·φ′)²，并比较展开底口折线与三维底口折线长度；
- 环境：Windows，Python 3.10.6。

## 发现

- **F1 文档缺陷（已修复）**：docs/02 的圆底反解式误写为 H = A·√((2πA/(2π−δ))² − 1)，多了一个因子 A；正确式为 H = A·√((2π/(2π−δ))² − 1)。用旧式求 δ=180° 会得到 H=0（Θ=2π），完全错误。这是"锥体高度可自由调配以精确支付正曲率"这一设计工具的关键一环，已在 docs/02 修正。
- **F2 数值精度**：Θ 对 H 敏感（dΘ/dH ≈ −2πAH/(H²+A²)^{3/2}），H 必须保留 ≥4 位小数（0.8660 / 0.5590 / 0.4410 / 0.3317）。首轮运行时参考表把 H 写成 0.332（3 位小数），导致 0.093° 偏差而触发未通过；改用精确 H 后通过。docs/02 已加入精度提示。
- **F3 数值修正**：三角薄楔在 sz = 0.01（B = 0.005）时 Θ = 106.2910°、δ = 253.7090°；文档旧值 106.26° / 253.74° 是 B→0 的极限。docs/02 已区分"实际值 / 极限值"。

## 判定

**通过**。判据：解析对照相对误差 < 1e-10；极限行为相对误差 < 1e-6 且单调收敛；展开等距相对误差 < 1e-6；参考表偏差 < 0.01°；随机抽样无越界。

## 结论与后续

- 核心公式（Θ、δ、侧面积）、三种极限行为（H→0、H→∞、B→0）以及"展开映射保度量"全部得到数值确认；
- 反解式缺陷 F1 是本实验最重要的产出：修正后，任意目标角亏都能反解出唯一锥高，锥点策略在数学上完全可用；
- 后续扩展建议：把侧面积公式纳入制造指标（材料用量）校核；把展开等距检查升级为随机点集 + 自适应积分，覆盖更极端的缩放角。
