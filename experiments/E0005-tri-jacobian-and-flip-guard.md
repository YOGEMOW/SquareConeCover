# E0005 三角块雅可比校验 + 翻转防护（过程渲染图）

- 状态：**发现真实缺陷**（雅可比与有限差分不一致）；翻转防护已实现并生效，但形状质量仍未达标
- 日期：2026-10-09
- 关联：E0004 已知问题、docs/08 §5.2

## 1. 雅可比有限差分校验（关键结果）

对 3×3 三角网格（18 个三角形）做数值微分对照：

| 检查项 | 结果 |
| --- | --- |
| 标量实现 vs 向量化实现的残差 | 4.0e-16（一致）|
| 标量实现的雅可比 vs 有限差分 | **3.33（不一致，应为 ~1e-6）** |
| 向量化实现的雅可比 vs 有限差分（含折痕块） | **8.57（不一致）** |

结论：三角块的解析雅可比与真实导数不符（误差 O(1)），**这是此前折皱/翻转问题的根因之一**——高斯-牛顿一直在一个错误的梯度方向上优化。必须先修掉这个实现缺陷，再谈能量设计。

## 2. 翻转防护（已实现）

在 GN 线搜索中加入"不允许新增翻转面"的判据（任何一步若使翻转面数增加就减半步长）。

结果（40×40 三角网格，crease=0.5，40 轮）：翻转面从显式控制的 0 保持住（对比：无防护时 198 个），但腰长差 p95 仍为 13.2%、共面性 0.036 —— 说明**仅靠防护不够，必须先修雅可比**。

## 4. 下一步（优先级）

1. **定位并修复雅可比缺陷**：建议先构造"单个三角形 + 一个残差行"的最小用例，逐项核对 ∂r/∂a、∂r/∂b、∂r/∂c；再查块内行号/列号映射（折痕块与面积块的行偏移是重点嫌疑）；
2. 修复后重跑本实验，确认 FD 校验降到 ~1e-6；
3. 再评估是否需要 ARAP 级弯曲能量。
