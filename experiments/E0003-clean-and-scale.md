# E0003 干净输入与规模验证（Stage A/A2）

- 状态：已完成
- 认领人：Codex（AI 协作者）
- 日期：2026-10-09
- 关联：Q15（新默认：用户指定优先、缺省最长边）、Q18（性能预算）、docs/08 §5.2

## 目标

1. 干净输入基线：已规整网格不应被改动（能量、位移、面积漂移都应为 0）；
2. 验证 Q15 新默认（底边 = 最长边）在干净三角网格上正确（能量应为 0）；
3. 圆柱面（可展）+ 单导轨锚定：应收敛到平坦矩形网格（共面性 + 面积漂移检查）；
4. 球冠（不可展）：规模下的稳定性与曲率残差下限；
5. 规模-性能基准：20/40/60 平面四边网格的每次迭代耗时。

## 方法

- 脚本：`experiments/scripts/E0003_clean_and_scale.py`（复用 E0002 核心，路线 A：高斯-牛顿 + 对角预条件 CG）
- 全部使用干净输入（无噪声、无预平滑）；面积参考 = 输入网格的全局面积
- 用例：C1 平面四边 40×40；C2 平面三角 40×40（底=最长边）；C3 圆柱面 24×20（单导轨锚定）；C4 球冠 20×20
- 性能：带 3% 扰动的平面四边网格 20/40/60，各跑 3 轮高斯-牛顿，统计每次迭代耗时

## 判定

- **C1 / C2 通过**：能量 ≈ 1e-24、位移 0、面积漂移 0 —— "干净输入不动作"基线成立；同时验证 Q15 新默认（底边=最长边）在干净输入下能量为 0。
- **C3 通过**：残差 0.854°（目标 ≤1°）、面积漂移 −0.08%（等距展平）、共面性下降 96%、翻转 0。
- **C4 通过（稳定性）**：残差 1.045°（不可展曲面下限）、面积漂移 −0.24%、位移 0.002、翻转 0。
- **性能未达标**：60×60（3721 顶点）需 9.6 s/轮；按当前实现外推 5 万顶点约需数百秒/轮，远超 Q18 的 ≤10 s 预算。

## 发现

1. **F1（性能瓶颈）**：雅可比装配使用 Python 三级循环（面 × 角点 × 坐标），是主要耗时来源；必须向量化（numpy 批量构造 COO）才能达到 Q18 预算，预计提速 10–50×。
2. **F2（预条件收益）**：对角预条件共轭梯度让圆柱面在 18 轮内收敛（E0002 中同一算例的路线 A 曾停滞在 1.74°）；新增"能量 < 1e-18 立即返回"使基线用例 0 轮退出。
3. **F3（干净输入无动作）**：C1/C2 位移严格为 0，说明能量模型在已规整网格上不会产生伪优化。
4. **F4（Q15 验证）**：底边=最长边时，对角线切分三角网格能量 ≈ 2e-24（零）；对照 E0002 F4，"最短边"默认在同类网格上失败（腰长差 41.4% + 翻转）。

## 结论与后续

- 干净输入基线与 Q15 新默认均通过；圆柱面可等距展平且面积代价极小（−0.08%）；
- 下一步优先级：**向量化雅可比装配 → 复测 5 万顶点性能预算**，然后再进 Blender 实现（M4 后半段）；
- 建议新增 E0004：向量化后的性能复测（目标 ≤10 s/轮 @ 5 万顶点）。
