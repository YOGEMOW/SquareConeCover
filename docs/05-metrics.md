# 验收指标与报告格式

> 所有指标必须可脚本化复现；编号 M1–M7 供 Issue / PR / 实验引用。

## 0. 采样与定义

- 采样：模型表面面积加权采样（默认 10⁵ 点，可按模型尺寸调整）；实例表面另行网格采样用于覆盖判定。
- 距离：d(x, patch) 为点到图元完整表面的欧氏距离（锥体包含侧面与底口圆盘）。
- 单位：米与毫米同时给出；相对量用"×片特征尺寸"或"×模型直径"归一。

## 1. 指标定义

### M1 贴合误差

- mean / p90 / p99 / max，按面积加权；
- 双向版本：模型→实例（贴合）与实例→模型（悬空/穿模）。

### M2 未覆盖与缝宽

- 未覆盖面积占比；
- 缝宽分布：对未覆盖区域做距离变换，报告 p50 / p95 / max；
- 缝隙网络：缝线总长度、交叉点数。

### M3 重叠

- 重叠面积占比（表面解释）或重叠体积（实体解释，取决于 Q1）；
- 最大穿透深度（若要求不穿模）。

### M4 曲率匹配

- 每锥：|δ_cone − ∫_patch K dA| / max(|∫K dA|, ε)；
- 全局：|Σδ_all − 2πχ|（闭合模型）；带边界模型需附边界项说明；
- 分布：锥点位置与曲率峰的距离统计。

### M5 形状健康

- 每片长宽比（矩形 a/b；锥体 max(A,B,H)/min(A,B,H)）；
- 退化计数（任一边 < 阈值、细长比 > 上限）；
- 缩放越界计数（超出 [0.01, 50]）。

### M6 视觉规律

- 缝线方向直方图（角度模块化到 [0, 90°)）；
- 片尺寸分布（面积直方图、变异系数）；
- 对称性得分（可选：与模型对称群的匹配度）。

### M7 稳定性

- 自交检查（实例级 + 全局）；
- 法向翻转检查；
- 求解收敛性（能量曲线、迭代次数、是否收敛）。

## 3. 验收阈值（占位，待 Q5 确认）

| 指标 | 建议阈值 | 状态 |
| --- | --- | --- |
| M1 p99 | ≤ 5 mm（1 m 片，R ≥ 25 m） | 待定 |
| M2 未覆盖率 | ≤ 5% | 待定 |
| M2 缝宽 p95 | ≤ 10 mm | 待定 |
| M4 相对误差 | ≤ 20% | 待定 |
| M5 退化 | 0 | 建议固定 |
| M7 自交 | 0 | 建议固定 |

## 4. 报告纪律

- 任何"通过/失败"结论必须附：模型 ID、参数、随机种子、脚本版本、原始 JSON；
- 不允许手改数值后复述；不确定处必须标注"未验证"。
