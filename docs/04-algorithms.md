# 算法框架

> 本文件描述 Stage B（图元拟合）：未知量是"实例变换"，不是网格顶点（C3–C8）。其前置 Stage A（网格规整化，允许动顶点）见 docs/08。

## 0. 流水线总览

    模型 → [1 分析] → [2 分区分类] → [3 单块拟合] → [4 全局布局] → [5 报告]
                                                      ↑________↓

## 1. 分析（Stage 1）

输入：模型网格（三角或四边）。
输出：采样点集 + 法向、曲率、分区种子。

- 采样：面积加权均匀采样（可选曲率自适应加密）；
- 离散高斯曲率：角亏法（顶点处 2π − Σ角度，除以顶点面积）；或用二次曲面拟合；
- 曲率符号图：K > +ε（凸）、|K| < ε（平）、K < −ε（鞍）；
- 曲率峰检测：局部极大 |K| 或凸起区域（用于布置锥点）；
- 可选：主曲率方向（指导矩形铺排方向与缝线走向）。

## 2. 分区与分类（Stage 2）

| 条件 | 类型 | 依据 |
| --- | --- | --- |
| 区域近似平面（残差 < t1） | 矩形片 | 方片天然零曲率 |
| 区域含正曲率峰 / 凸壳 | 锥片 | 锥体交付正曲率 δ |
| 区域含负曲率（鞍） | 缝带 | 无图元可支付负曲率 |
| 视觉设计图案需求 | 楔片 / 圆片 / 椭圆片 | 锥体的两种扁平用法 |

候选分区手段：区域生长（Region Growing）、变分形状逼近（VSA，K-means 式）、曲率线分割、D-Charts 式可展性分割。

## 3. 单块拟合（Stage 3）

### 3.1 通用子例程：带轴缩放约束的 Procrustes

给定局部坐标 x_i 与世界坐标 y_i（对应点），求 T、R、s 最小化 Σ‖T + R·diag(s)·x_i − y_i‖²：

1. 固定 s，令 z_i = diag(s)·x_i，用标准 SVD（Kabsch/Umeyama）求 R 与 T；
2. 固定 R、T，对 s 求最小二乘（对 s 是线性的，可逐分量解三元线性系统）；
3. 交替 1–2 轮直至收敛。

注意：不允许把 R 与 S 合并成一般 3×3 矩阵（那会产生剪切，违反 C6）。

### 3.2 矩形拟合

1. 区域采样点 PCA → 平面与面内两个主方向；
2. 面内投影 → 包围盒 / 分位数收缩（抗离群）；
3. 输出：中心、旋转（法向 + 面内方向）、sx、sz；
4. 残差 = 点到平面的距离 + 边界溢出惩罚。

### 3.3 锥体拟合

变量：顶点位置与轴（5 个自由度），底半轴 A、B 与高 H。

1. 用曲率峰/凸壳估计轴方向与顶点初值（PCA 主轴或法向平均）；
2. 固定形状：把采样点投影到锥面求最近点 → 用 §3.1 更新位姿；
3. 固定位姿：对 A、B、H 做一维扫描或 Gauss-Newton（残差可解析求导）；
4. 加入锥口贴面残差：锥口附近采样点到模型表面的距离（避免悬空锥）；
5. 输出 δ，并与所在区域 ∫K dA 对照（账本一致性检查）。

### 3.4 楔片与圆片拟合

- 楔片（等腰三角）：轮廓平面拟合 + 三角形参数（底方向、底长、高、顶角）最小二乘；噪声场景可用凸包或 RANSAC；
- 圆/椭圆片：平面拟合 + 椭圆半轴与朝向拟合（即 sy = 0.01 的锥体拟合退化情形）。

## 4. 全局布局（Stage 4）

### 4.1 局部-全局迭代（默认方案）

    repeat:
        分配步：把采样点分给"距离最近"的实例（可加重叠/缝隙罚项）
        拟合步：对每个实例独立调用 Stage 3 拟合器
    until 能量下降 < 阈值 或 达到最大迭代

与经典 Lloyd/ARAP 的局部-全局同构，但局部步解的是实例变换，比顶点优化更稳定。

### 4.2 缝线骨架法（结构先验）

1. 在曲率图上先规划缝线（曲率线、测地线、视觉基准线）；
2. 沿缝线生长：先铺矩形带，再在正曲率峰插入锥点；
3. 用 L²/(8R) 估算缝宽预算，反推片尺寸。

### 4.3 逃逸局部最优

- 多起点（不同种子与初始分区）；
- 退火与随机重启（片数、位置、朝向扰动）；
- 由粗到细（先大尺度覆盖，再细化缝带附近）；
- 片数较少（< 50）时可用小规模 MILP / CP-SAT（离散化位置与朝向）。

### 4.4 平凡解抑制

必须同时使用：尺寸离散度惩罚、多重覆盖约束、局部贴合残差、长宽比上限；否则"一块 50×50 m 巨片"会轻易获胜。

## 5. 报告（Stage 5）

- 指标 JSON（见 docs/05）；
- 渲染图：正视/侧视/等轴视图 + 缝隙高亮；
- 残差曲线：能量 vs 迭代；
- 检查项：自交、法向翻转、退化（细长比越界）、缩放越界。
