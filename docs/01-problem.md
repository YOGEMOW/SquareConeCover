# 问题定义与约束

## 1. 一句话定义

用"边长 1 m 正方形平面"与"高 1 m / 底半径 0.5 m 圆锥"两类图元的实例，通过整体平移、旋转与自身轴缩放，覆盖拟合任意三维模型表面，允许细小缝隙与重叠。

## 2. 约束清单（C 编号）

| 编号 | 约束 | 说明 |
| --- | --- | --- |
| C1 | 图元 A = 边长 1 m 的正方形平面 | 默认水平放置，法向 +Y |
| C2 | 图元 B = 高 1 m、底半径 0.5 m 的圆锥 | 默认轴 +Y，底口圆位于 XZ 平面 |
| C3 | 每个实例仅允许整体平移、旋转、沿自身轴缩放 | 变换顺序 T·R·S，共 9 个自由度 |
| C4 | 缩放各轴独立，范围 [0.01, 50] | 允许非等比缩放 |
| C5 | 缩放分量必须为正 | 禁止负缩放与镜像 |
| C6 | 不得修改图元的轴向定义 | 缩放作用在图元自身 XYZ 上 |
| C7 | 不得进行顶点级编辑 | 不允许移动、增删、合并节点 |
| C8 | 不得裁切、截顶、斜切底口 | 图元必须保持完整 |
| C9 | 世界坐标 Y 轴朝上，单位米 | 所有输入输出遵循此约定 |
| C10 | 允许细小缝隙与重叠 | 要求"不显眼"；阈值待定（Q4） |
| C11 | 覆盖对象为任意三维模型表面 | 封闭或开放待定（Q3） |
| C12 | 结果必须可复现 | 实例列表 + 参数 + 指标报告，缺一不可 |

## 3. 允许与禁止（速查）

允许：

- 非等比缩放（每轴 0.01–50）
- 任意旋转（含 180° 翻转）
- 缝隙、重叠
- 锥体压扁成圆/椭圆片（sy = 0.01）
- 锥体压扁成等腰三角片（sx 或 sz = 0.01）

禁止：

- 负缩放、镜像
- 裁切、截顶、斜切、局部变形
- 顶点级编辑
- 修改图元轴向定义

## 4. 目标（定性）

1. **贴合**：覆盖片尽量贴住模型表面；
2. **规整**：每片保持理想形状族（直角、等腰、正锥），整体观感有序；
3. **可控**：缝隙与重叠在阈值内且分布合理；
4. **可复现**：任何人（含 AI）用同一份 scene.json 与指标脚本能得到相同结论。

## 5. 与经典问题的关系

| 经典问题 | 关系 |
| --- | --- |
| 建筑表皮面板化（Eigensatz 2010） | 同族问题：面板覆盖自由曲面并控制接缝 |
| 网格规整化（PQ 网格、平面化） | 目标相近，但那里允许移动顶点，本项目禁止 |
| 各向同性重网格化 | 生成近等边三角网，可作区域分割参考 |
| 可展分割 / 纸模型展开 | 提供"每片可展"的分解思路 |
| 锥奇异点 / 曲率预设 | 本项目"锥点策略"的直接来源 |

## 6. 术语表

| 术语 | 含义 |
| --- | --- |
| 图元（primitive） | 未变换的正方形平面或圆锥 |
| 实例（instance） | 图元经过缩放、旋转、平移后的个体 |
| 曲率量子 δ | 锥顶角亏 = 2π − Θ |
| 缝带 | 允许缝隙/重叠的带状区域，通常位于负曲率处 |
| 锥点 | 承担正曲率的锥体顶点位置 |
