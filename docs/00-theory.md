# 理论总纲

> 本文件是项目的"单一事实来源"（single source of truth）。实现、测试、评审都以本文的编号体系为准：约束 C（docs/01）、开放问题 Q（docs/07）、实验 E（experiments/）。

## 1. 问题陈述

给定三维模型表面（Y 轴朝上，单位米），先做网格规整化（Stage A，docs/08），再求一组图元实例覆盖并拟合规整后的表面（Stage B）：

- 图元 A：边长 1 m 的正方形平面（默认法向 +Y）；
- 图元 B：高 1 m、底半径 0.5 m 的圆锥（轴 +Y，底口在 XZ 平面，图元必须完整）。

每个实例只允许整体平移、旋转与沿自身轴的独立正缩放（区间 [0.01, 50]）。允许细小缝隙与重叠，但要求整体"看起来规整"。目标是给出可量化、可复现的最优或近似最优覆盖。

精确密铺在一般情况下不存在（顶点共享导致各片的理想形状互相冲突），因此问题定位为**最小残差的面板化**：把所有理想形状写成误差项，求全局最小残差。

## 2. 形式化

实例变换（先缩放、再旋转、最后平移）：

    x_world = T + R · S · x_local,  S = diag(sx, sy, sz),  sx, sy, sz ∈ [0.01, 50]

性质：

- 无剪切（缩放轴固定为图元自身轴），无镜像（缩放分量恒正）；
- 方片的 sy 无几何意义；方片实例 8 个有效自由度，锥体实例 9 个；
- 注意：C3–C8 约束的是 Stage B 的图元实例；Stage A（网格规整化）允许移动网格顶点，见 docs/08。

## 3. 形状族结论

### 3.1 方片 → 矩形族

缩放后为 a×b 矩形（a = sx, b = sz），直角保持，面积 sx·sz。长宽比可达 5000:1，需要附加长宽比上限约束（Q6）。

### 3.2 锥体 → 正椭底锥族

参数：底半轴 A = 0.5sx（X 向）、B = 0.5sz（Z 向）、高 H = sy。因为缩放沿自身轴、顶点始终位于底椭圆中心正上方，永远不会出现斜锥。

顶点总角与曲率量子：

    Θ = ∫₀^{2π} √(B²H²cos²t + A²B² + A²H²sin²t) / (H² + A²cos²t + B²sin²t) dt
    δ = 2π − Θ

侧面积：

    S = ½ ∫₀^{2π} √(B²H²cos²t + A²B² + A²H²sin²t) dt

圆底（A = B）退化为经典结果：Θ = 2πA / √(H² + A²)。

推导要点：以 P(t,u) = apex + u·(p(t) − apex) 参数化，p(t) = (A cos t, 0, B sin t)，第一基本形式行列式 det g = u²|p′×(p−apex)|²，绕顶点角度测度 dφ/dt = |p′×(p−apex)|/|p−apex|²。注意：只含 cos²/sin² 的简化式仅对圆底成立，椭底必须用上式。

### 3.3 缩放区间 [0.01, 50] 的三重含义

1. 单块最大 50 m（方片最大 50×50 m），覆盖大模型时片数不受面积上限约束；
2. 单块最小 0.01 m，可做细节填充；
3. 极端长宽比（最大 5000:1）容易让优化器退化成细长条，必须显式限制长宽比与细长比（Q6）。

## 4. 曲率账本（可行性边界）

- 高斯-博内：对闭合曲面 Σδ = 2πχ（球面 720°、圆环面 0°）；带边界曲面需另加边界测地曲率项。
- 锥体 δ ∈ (0, 2π)，随缩放连续可调，但**恒为正**：负曲率（鞍形）区域无法被任何图元"消化"，只能成为缝带。
- 若严格拼接：矩形角点提供 90° 的离散量子，锥体提供连续量子；纯矩形区的曲率谱只能是 90° 的整数组合。
- 设计原则：把正曲率集中到少数锥点（锥奇异点策略），把不可避免的误差（尤其负曲率）赶进缝带。
- 尺寸-缝宽关系：弓高 ≈ L²/(8R)。L = 1 m、R = 10 m 时约 12.5 mm。

## 5. 算法框架（Stage B，五阶段）

前置 Stage A（网格规整化，允许动顶点）见 docs/08；下述五阶段处理规整后的网格。

1. **分析**：采样、法向、离散高斯曲率（角亏法）、曲率符号图、曲率峰检测；
2. **分区与分类**：平面区 → 矩形；正曲率峰/壳 → 锥；负曲率 → 缝带；设计图案区 → 楔片/圆片；
3. **单块拟合**：矩形（PCA + 面内包围盒）、锥（顶点/轴/底椭圆/高的交替最小二乘）、楔（轮廓三角形拟合）。核心子例程是"带轴缩放约束的 Procrustes"：旋转用 SVD，缩放对坐标线性可直接最小二乘，两者交替；
4. **全局布局**：局部-全局迭代（分配 ↔ 拟合）、缝线骨架生长、可选小规模 MILP 或退火，目标函数见 §6；
5. **报告**：指标 JSON + 渲染图 + 残差曲线 + 自交/翻转检查。

## 6. 目标函数草案

    E = Σ_patches 拟合残差²
      + w_gap     · 未覆盖量（缝）
      + w_overlap · 重叠量
      + w_ar      · 长宽比/细长比惩罚
      + w_size    · 尺寸离散度（抑制尺寸悬殊）
      + w_count   · 片数
      + w_pattern · 图案/对齐正则

平凡解抑制：无附加约束时"一块 50×50 m 巨片盖住一切"会轻易获胜，必须用尺寸离散度、多重覆盖约束与局部贴合残差共同压制。

## 7. 验收指标（详见 docs/05）

M1 贴合误差（mean/p90/p99/max，面积加权）；M2 未覆盖率与缝宽分布；M3 重叠占比；M4 曲率匹配（每锥 |δ − ∫K dA| 与全局 Σδ vs 2πχ 偏差）；M5 形状健康（长宽比、退化计数、缩放越界）；M6 视觉规律（缝线方向直方图、尺寸分布、对称性）；M7 稳定性（自交/翻转/退化）。
