# 网格规整化（Stage A，Blender 阶段）

> 两阶段流水线的第一阶段：在 Blender 中把模型网格的面规整到两个图元的理想形状族，为第二阶段的图元拟合创造条件。

## 1. 定位：两阶段流水线

    原始模型 → [Stage A 网格规整化（动顶点）] → 规整网格 + 残差报告 → [Stage B 图元拟合（只动实例）] → 场景/面板

- **Stage A（本文件）**：允许修改网格顶点坐标，在 Blender 内完成；目标是让每个面尽量接近"可被图元精确覆盖"的理想形状。Stage A 内部再分两步（Q14 决议，2026-10-09）：
  - **A1 重网格化（可选、默认关闭）**：改变拓扑与顶点数，用于修复价数分布、面尺寸均匀性与退化面；
  - **A2 位置规整（本文件主体）**：严格保持拓扑与顶点数，只移动顶点坐标。
- **Stage B（docs/04）**：顶点冻结，只允许图元实例的平移、旋转、自身轴缩放（约束 C3–C8）。

形状对应关系（整个流水线的关键设计）：

| 网格面 | 理想形状 | 对应图元用法 | 精确性 |
| --- | --- | --- | --- |
| 四边形 | 矩形（平面） | 正方形平面 → 矩形（sx, sz） | 精确 |
| 三角形 | 等腰三角形（平面） | 圆锥压扁（sz=0.01）→ 等腰三角薄楔 | 精确（轮廓） |
| 顶点扇面（可选） | 锥面（锥顶落在网格顶点） | 圆锥（一般缩放） | 近似，受扇面形状限制 |
| 其他面（退路） | 椭圆 | 圆锥压扁（sy=0.01） | 近似 |

说明：矩形族与等腰三角形族都允许任意长宽比/顶角（由缩放自由度提供），因此规整化不需要把面压成固定尺寸或固定角度，只需要"形状族正确 + 平面 + 无退化"。

## 2. 未知量与约束

- 未知量：选中区域内所有顶点坐标 x ∈ R^{3n}；
- 锚点：选区边界顶点 + 用户标记点（默认顶点组 SC_Anchor）；权重极大（硬约束或大权重软约束）；
- 禁止：面翻转、面积趋零；选区外顶点不动；
- 可选保持：逐面面积（防膨胀）、整体体积、边界长度、边长度均匀性。

## 3. 能量项

记四边形 f = (v1,v2,v3,v4)、三角形 t = (a,b,c)。

### 3.1 四边形 → 矩形

1. 平行四边形（线性残差）：
   r_par = v1 + v3 − v2 − v4，E_par = Σ |r_par|²
2. 对角线相等（补齐"矩形"）：
   r_diag = |v1 − v3|² − |v2 − v4|²，E_diag = Σ r_diag²
   平行四边形 + 对角线相等 ⟺ 矩形。
3. 共面度：
   四顶点到最佳平面距离平方和（或两个三角形法向夹角）。

### 3.2 三角形 → 等腰三角形

指定底边 (a, b)，等腰条件等价于

    r_iso = c·(b − a) − (|b|² − |a|²)/2 = 0

几何含义：c 落在底边的垂直平分面上；该式对 c 线性、对 a 与 b 二次，适合高斯-牛顿或局部-全局。

- 底边规则：默认最短边；可用户指定；可选"逐面取残差最小者"（但选定后应保持稳定，避免震荡）；
- 可选加强：等边（|c−a|² = |b−a|²）；最小内角下界（防退化薄三角）。

### 3.3 通用项

- 面积保持：E_area = Σ (A_f − A_f⁰)²（防膨胀，见 §5）；
- 位置项：E_pos = Σ |v − v⁰|²；
- 拉普拉斯平滑：E_smooth = Σ |v − mean(N(v))|²；
- 锚点项：E_anchor = Σ_{v ∈ 锚点} W|v − v⁰|²（W 很大）。

总能量：E = Σ_faces w_f·E_face + w_area·E_area + w_pos·E_pos + w_smooth·E_smooth + E_anchor。

## 4. 求解路线

### 路线 A：线性化 + 高斯-牛顿（精度优先）

- 对 E 求 Jacobian（r_par 线性、r_diag 与 r_iso 二次）；
- 正规方程 (JᵀJ + λI)·Δx = −Jᵀr（稀疏 SPD）；
- 自写共轭梯度（Jacobi 预条件）求解；λ 用 LM 自适应；
- 单轮成本 O(nnz)；收敛判据：能量下降 < 0.1% 且残差 < 容差。

### 路线 B：局部-全局迭代（稳健优先，推荐先跑）

局部步（逐面求最近理想形状）：

- 四边形：PCA 求最佳平面 → 平面内拟合最接近的矩形；
- 三角形：把顶点 c 投影到底边 (a, b) 的垂直平分面（最小位移），高度保持或最小化；

全局步：固定每面目标形状，解一个稀疏线性系统（拉普拉斯 + 锚点权重），即 E 的二次近似；

交替迭代 20–200 轮，带阻尼与步长限制以防翻转。

推荐流程：先 B 粗调（快、稳），再用 A 收尾（精度高）。

## 5. 稳定性与关键细节

- **防膨胀**：矩形/等腰约束本身允许尺寸自由变化（例如三角顶点可沿垂直平分面跑很远），必须补面积或边长软约束，否则解算会把面撑大；
- **防翻转**：限制单步位移不超过局部边长的一定比例；迭代后检查法向一致性；
- **底边稳定**：三角形底边选定后尽量保持；
- **边界策略**：选区边界默认锚定；需要平滑过渡时用"软边界"（权重随距离衰减）；
- **退化面**：面积低于阈值的面直接标记并跳过；
- **收敛停滞**：路线 A 提高 λ，路线 B 减小步长或重启局部步。

### 5.1 E0002 实测补充（2026-10-09）

- **面积项必须是全局的**：逐面面积保持与形状规整化在噪声输入上不可兼得；请用全局面积项防膨胀，逐面漂移只作报告指标；
- **平滑项用拉普拉斯形式**：`Σ|v − mean(N(v))|²`（平面网格上恒为零）；"膜能量"`Σ|v_i − v_j|²` 会推动收缩、与形状约束冲突；
- **锚点必须是硬约束**：只对自由顶点建立未知量，禁止"先当变量、后归零"；
- **求解器推荐**：路线 A（高斯-牛顿）为主，路线 B（局部-全局）作可选粗调（E0002 中它在圆柱面上发散）；
- **底边规则**：对由四边形对角线切分得到的三角网格，底边应取对角线（=最长边）；"最短边"默认会失败（E0002 F4）；
- **锚点策略**：优先锚定可展导轨或少量控制点；整圈/双导轨硬锚会迫使压缩，与面积约束冲突（E0002 F6）；
- **预平滑**：优化前 2–3 轮拉普拉斯预平滑可显著改善初值（本原型默认开启）。

### 5.2 E0003 实测补充（2026-10-09，干净输入与规模）

- **干净输入基线**：已规整的平面四边/三角网格能量 ≈ 1e-24、位移 0（不会发生"伪优化"）；
- **Q15 新默认（缺省最长边）**：干净三角网格能量为零，验证通过；
- **圆柱面等距展平**（单导轨锚定）：残差 0.854°、面积漂移 −0.08%、共面性下降 96%、无翻转；
- **球冠**：稳定，残差 1.045°（曲率下限），面积漂移 −0.24%；
- **性能未达标（重要）**：当前 Python 三级循环装配雅可比，3721 顶点需 9.6 s/轮；外推 5 万顶点约数百秒/轮，远超 Q18 的 ≤10 s 预算。**实现时必须向量化装配**（预计提速 10–50×），再复测预算。
- **E0004 已修复并达标**：全部改用 numpy 批量构造稀疏结构后约 20× 提速 —— 3,721 顶点 0.44 s/轮、49,284 顶点 5.39 s/轮（目标 ≤10 s/轮）。
- **精度策略（E0004 F2）**：内层 PCG 的精度会影响结果质量（低精度下圆柱面可能停在未展平的中间状态）；小/中网格用 tol=1e-13，大网格快速模式需配合更多轮次或更强预条件，并在报告中记录内层残差。

## 6. Blender 落地

| 事项 | 方案 |
| --- | --- |
| 数据读写 | bpy + bmesh 读取选区；numpy 数组求解；`mesh.vertices.foreach_set("co", flat)` 写回 |
| 选区 | 顶点选择子集或顶点组（默认 SC_Region） |
| 锚点 | 选区边界 + 顶点组 SC_Anchor |
| 撤销 | 应用前 `bpy.ops.ed.undo_push(message="SC: regularize")` |
| 预览 | Dry-run：只输出残差报告，不改网格 |
| 求解器 | 自写共轭梯度（Blender 自带 Python 无 scipy） |
| 报告 | 残差 JSON + 控制台摘要 + 可选 Text datablock |
| 面板 | bl_idname 前缀 SC_；参数含权重、迭代数、底边规则、面积保持开关 |
| 性能 | 5 万顶点/5 万面量级下稀疏 CG 每轮秒级；必要时多分辨率（先粗后细） |

Geometry Nodes 的 Repeat Zone 能迭代，但不适合做矩阵求解；求解放在 Python 侧。

## 7. 阶段产物（交给 Stage B 的接口）

1. 规整化后的网格（顶点坐标已更新）；
2. `mesh_regularization_report.json`（建议字段）：
   - per_face: face_id, type(quad/tri/ngon), residual_par, residual_diag, planarity, isosceles_residual, base_edge, min_angle, aspect
   - per_vertex: angle_defect, is_anchor
   - global: energy_curve, iterations, max_displacement, flipped_faces, degenerate_faces, area_drift
3. 三角形底边指定结果与锚点集合。

Stage B 直接消费 1+2：残差小的面可以被图元精确覆盖；残差大的面会在拟合阶段表现为缝隙/重叠并被报告。

## 8. 验收指标（Stage A）

| 指标 | 建议目标 |
| --- | --- |
| 四边形直角偏差 | p95 ≤ 1°，max ≤ 5° |
| 对边长度差 | p95 ≤ 1% |
| 共面度（四边面） | p95 ≤ 0.5% × 面对角线 |
| 三角面腰长差 | p95 ≤ 1% |
| 最小内角 | ≥ 15° |
| 面积漂移（全局） | ≤ 1% |
| 翻转面 | 0 |
| 最大位移 | 只报告，不设限 |
