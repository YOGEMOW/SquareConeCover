# SquareConeCover · 正方形与圆锥双图元覆盖拟合

用两个固定图元——**边长 1 m 的正方形平面**与**高 1 m、底半径 0.5 m 的圆锥**——通过**整体平移、旋转、沿自身轴的缩放**，去覆盖并拟合任意三维模型表面。

> 本仓库是"理论先行"的研究协作仓库：先把数学结论、约束、算法骨架与验收指标固化下来，再由人类协作者与 AI 一起实现、测试、迭代。

## 两阶段流水线

1. **Stage A · 网格规整化（Blender）**：允许修改顶点坐标，把四边形面拉成矩形、三角形面拉成等腰三角形（可选把顶点扇面锥化），见 docs/08；
2. **Stage B · 图元拟合**：顶点冻结，只用"平移 + 旋转 + 自身轴缩放"的图元实例覆盖规整后的模型，见 docs/04。

| 网格面 | 理想形状 | 对应图元 |
| --- | --- | --- |
| 四边形 | 矩形（平面） | 正方形平面（矩形缩放） |
| 三角形 | 等腰三角形（平面） | 圆锥压扁（sz=0.01） |
| 顶点扇面（可选） | 锥面 | 圆锥（一般缩放） |

## 为什么值得研究

1. 两个图元都是**可展曲面**：平面处处零高斯曲率，锥体除顶点外处处零曲率、顶点携带集中曲率。覆盖问题因此可以完全由高斯-博内定理给出可行性边界。
2. 变换被限制为"自身轴缩放 + 刚体位姿"：无剪切、无镜像、无裁切、无顶点编辑。求解对象从"网格变形"变成"每片 9 个自由度"的实例优化，问题结构更干净，更容易被不同工具链复现与交叉验证。
3. 精确密铺一般不存在，正解是**最小残差的面板化**：矩形铺平坦区、锥片集中正曲率、负曲率区域留缝。

## 图元与约束一览

| 项 | 内容 |
| --- | --- |
| 图元 A | 正方形平面，边长 1 m（默认法向 +Y，水平放置） |
| 图元 B | 圆锥，高 1 m，底半径 0.5 m（默认轴 +Y，底口在 XZ 平面） |
| 变换 | T·R·S：先沿自身 X/Y/Z 缩放 → 再旋转 → 最后平移 |
| 缩放范围 | 每轴 0.01 – 50，各轴独立，非等比允许 |
| 禁止 | 负缩放/镜像、裁切、截顶、斜切底口、顶点级编辑、修改图元轴向 |
| 允许 | 细小缝隙与重叠（需"不显眼"，阈值待定，见 Q4） |
| 表现形态 | 方片 → 矩形；锥体 → 圆/椭圆片、等腰三角片、椭底锥（见 docs/02） |
| 世界约定 | Y 轴朝上，单位米 |

## 核心结论速览

- 锥体顶点总角 Θ(A,B,H) = ∫₀^2π √(B²H²cos²t + A²B² + A²H²sin²t) / (H² + A²cos²t + B²sin²t) dt，曲率量子 δ = 2π − Θ，连续取值于 (0, 2π)；
- 默认锥（A=B=0.5, H=1）：Θ = 160.99°，δ = 199.01°，侧面积 1.756 m²；
- 闭合曲面必须满足 Σδ = 2πχ；球面按 4π/n 分摊角亏、圆底口径 1 m 时所需锥高：n=4 → 0.866 m，n=6 → 0.559 m，n=8 → 0.441 m，n=12 → 0.332 m；
- δ 恒为正 ⇒ **负曲率（鞍形）区域无法被任何图元吸收，只能成为缝带**；
- 不允许裁切 ⇒ 缝线集合 = 直线段（矩形边）∪ 椭圆弧（锥口）。

## 如何参与

**人类协作者**

- 新想法先查 `docs/07-open-questions.md`，没有再开新编号（Q 开头）。
- 测试与验证统一放 `experiments/`，用 E 编号与模板，附可复现步骤。
- 任何结论性的修改必须回写到 `docs/`，并在 PR 描述中引用编号。

**AI 协作者**

- 阅读顺序：`docs/00-theory.md` → `specs/conventions.md` → 任务相关文档 → 对应实验模板。
- 提交结果必须可复现：给出参数、方法、原始输出与判定结论；不允许只给"看起来正确"的结论。
- 不要静默修改约束：C 编号的变更必须同步更新 `docs/01-problem.md` 与 `docs/07-open-questions.md` 的已定项表。

## 术语表

| 术语 | 含义 |
| --- | --- |
| 图元（primitive） | 未变换的正方形平面或圆锥 |
| 实例（instance） | 图元经过缩放、旋转、平移后的个体 |
| 曲率量子 δ | 锥顶角亏 = 2π − Θ，锥体携带的集中曲率 |
| 缝带 | 允许存在缝隙/重叠的带状区域，通常位于负曲率处 |
| 锥点 | 把正曲率集中起来的锥体顶点位置 |
